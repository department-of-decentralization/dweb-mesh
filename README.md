# DWeb Camp 2026 — Mesh Docs

**Off-grid messaging and application mesh at DWeb Camp Berlin 2026.**

The entry point for joining the camp LoRa mesh, and the **portable memory** of it: how to
join, how to flash, where to get help when the radio goes silent.

Built to survive with **no upstream internet** — every byte ships in the bundle. Static
site, generated by [Zola](https://www.getzola.org/). The canonical decisions live in
[`SPEC.md`](SPEC.md); pass/fail criteria in [`ACCEPTANCE.md`](ACCEPTANCE.md); working
rules in [`CLAUDE.md`](CLAUDE.md).

## Quick start

```sh
zola serve          # dev server with live reload
zola build          # → ./public
scripts/check-offline.sh   # MUST pass: zero external assets in the build
```

Preview the built site exactly as deployed (served at site root, offline):

```sh
cd public && python3 -m http.server 8000   # → http://localhost:8000/
```

## Two deploy targets, one source

`base_url = "/"` → host-less root paths, so the **same build** works at both targets with
no DNS dependency.

- **GitHub Pages** (canonical, public) — automatic via
  [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) on push to `main`.
  One-time setup: repo **Settings → Pages → Source = "GitHub Actions"**. The custom domain
  `mesh.dod.ngo` is carried by the `CNAME` file (the workflow copies it into the artifact).
- **Freifunk wifi** (offline) — **manual drop**. Run `zola build` and copy the `public/`
  directory onto the Freifunk host. No CI, no sync.

If Pages ever serves from a subpath instead of the custom domain, rebuild with
`zola build --base-url /<subpath>/` — all links go through `get_url`, so that's the only change.

## Layout

```
config.toml            base_url, site config
content/               Markdown — one dir/page per route
templates/             base, section, page, index, 404, robots, sitemap
static/css/style.css   hand-written CRT/terminal theme
static/fonts/          bundled OFL/MIT fonts (+ licenses)
static/js/counters.js  the only dynamic bit (splash counters)
static/stats.json      sample the Mesh Nest box overwrites live
scripts/check-offline.sh   self-containment gate (run in CI too)
```

## Constraints (non-negotiable)

No CDN, webfonts, external JS, analytics, or remote anything — one external asset is a
broken page on the offline copy. Three stacks (Meshcore primary, Meshtastic supported,
Reticulum educational) are **parallel with no bridges**. See `CLAUDE.md`.

Bundled fonts: Press Start 2P (OFL) and Departure Mono (MIT) — see `static/fonts/SOURCES.md`.
