**Build a web app on Reticulum — without internet.**

Reticulum can serve "pages" the way the early web did, but over encrypted mesh links and
with no internet at all. The tool is **Nomad Network** (`nomadnet`): it hosts pages
written in a light markup and serves them to other Reticulum nodes — a tiny, self-hosted
web that works when the internet doesn't.

The camp workshop walks through standing up a node and publishing a page others can reach
over Reticulum. Watch the [Agenda](@/agenda/_index.md) for the slot, or ask at the
[Mesh Nest](@/mesh-nest/_index.md).

```
pip install nomadnet
nomadnet
```

> Reticulum is **educational / workshops only** and does **not bridge** to Meshcore or
> Meshtastic. No production traffic is expected here.
